### ♪ BGM 듣는 방법

1. 화면 오른쪽 위, **`♪ BGM ↗`** 버튼을 눌러주세요.
2. Geuni가 직접 생성한 Suno의 곡 페이지가 열립니다.
3. 픽셀, 크리스마스 테마를 반영하여 만든 곡입니다. bgm과 함께 사이트를 둘러보세요!

## 만든 방법

- **구성:** HTML · CSS · JavaScript로 구현한 정적 사이트이며, Github로 배포함.
- **그림:** 고양이, 트리, 선물 상자, 언덕, 구름은 직접 생성하였습니다.
- **글꼴:** [Galmuri](https://github.com/quiple/galmuri)(픽셀 글꼴), [Pretendard](https://github.com/orioncactus/pretendard). 
- **제작 도구:** Claude Code, Codex
- **음악:** Suno

```
Pf-page/
├── index.html   # 페이지 구조와 내용
├── style.css    # 테마 색상, 픽셀 스타일, 모바일 대응
├── theme.js     # 다크 모드, 복사 버튼, 고양이·선물 상자, 눈·전구 효과
└── robots.txt   # AI 학습용 크롤러 수집 거부
```
